## Status

This project is a resurrected legacy D3D9 advanced-rendering demo.

It is preserved as a reference implementation for:
- MD3 character rendering
- shader profile loading
- shadow-map render pass setup
- HDR/bloom post-processing setup

The original shader/profile/media layout is intentionally left mostly intact.
Further cleanup is deferred. This project is not intended to become the long-term renderer architecture.
